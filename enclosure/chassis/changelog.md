# Chassis change log


## v2.1 - 2025-04-20
Visual improvements.

### Changed
 - increased all fillet radii to 3 mm
 - changed the bottom holes distances to be more regular
 - moved the thread supports to avoid covering the holes
 - increased USB cutout's size
 - moved the name and version to the outside bottom as deboss


## v2.0 - 2025-04-03
Added hole for the USB-C port, visual and minor functional improvements.

### Added
 - name cutout on the back side
 - holes on the bottom
 - cutout for the USB-C receptacle
 - deboss for rubber legs

### Changed
 - moved the name cutout to the right
 - wire cutouts from rectangle to ellipse
 - moved the top-right thread insert hole to match the PCB and the top plate

### Removed
 - cutouts for the UART header and the antenna
